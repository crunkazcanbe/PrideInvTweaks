# Pride InvTweaks

Small inventory polish for **Minecraft 1.12.2** big modpacks:
- **Hides missing-texture items** (the purple-and-black ones) everywhere — inventory and HEI/JEI — with a key to toggle it.
- **Centers items** neatly in inventory slots.
- A **Pride Tweaks…** button on the Options screen to set it up.
